# Кабинет партнёра Геномед — демо-прототип

Новый личный кабинет для клиник-партнёров лаборатории Геномед: заказ исследований, преаналитика, печать бланка и штрих-кодов, вызов курьера, расходные материалы, перезаборы и заключения.

Все пациенты, заказы, цены, имена менеджеров и телефоны (кроме клиентского сервиса 8 (495) 660-83-77) выдуманы. Входа нет: кабинет открывается сразу под демо-клиникой. Данные хранятся в браузере, кнопка «Сбросить демо-данные» — в профиле клиники.

## Как открыть

Онлайн: ссылка GitHub Pages в описании репозитория.

Локально: любой статический сервер из корня папки, например

```
python3 -m http.server 8000
```

и открыть http://127.0.0.1:8000. Сборка не нужна.

## Пожелания партнёров и где они решены

| № | Пожелание | Где в кабинете |
|---|---|---|
| 1 | Дозаказ сырых данных не висит в черновиках | Карточка заказа и «Заключения» → «Дозаказать сырые данные». Заказ сразу уходит в работу со статусом «В лаборатории», связан с исходным |
| 2 | Поменять местами «Штрих-код» и «Вызов курьера» | В карточке заказа шаги идут по порядку работы: бланк → штрих-коды → курьер. Штрих-коды можно перепечатать и после вызова курьера |
| 3 | Заказ расходного материала | Раздел «Расходные материалы»: количество упаковок, доставка с ближайшим курьером или отдельно, история заказов |
| 4 | Печать бланка заказа после регистрации | После сохранения бланк с данными пациента и исследованиями печатается автоматически (настраивается в профиле) |
| 5 | Код услуги рядом с названием | Во всех списках, карточке, бланке и выгрузке |
| 6 | «Редактировать» после сохранения и до вызова курьера | Кнопка в карточке и в меню строки. Если курьер вызван, кабинет объясняет почему и предлагает отменить вызов |
| 7 | Все заказы, включая бумажные | «Мои заказы»: метка «бумажный бланк» и фильтр по источнику |
| 8 | Убрать «оплачен» из «Заключений» | Статусы заключений только про готовность: «Готово», «Готово 1 из 2», «Ожидается» |
| 9 | Автопечать ИДС для Panorama | Если в заказе Panorama, после сохранения вместе с бланком печатается ИДС |
| 10 | Дата рождения без точек | Ввод «07071997» превращается в «07.07.1997», проверяется существование даты, показывается возраст |
| 11 | Преаналитика привязана к тестам | Блок «Что взять у пациента» собирает пробирки и их количество из выбранных исследований; для тестов с вариантами биоматериала есть выбор |
| 12 | Сегодняшняя дата в календаре | Во всех календарях сегодняшний день обведён, есть кнопка «Сегодня» |

## Что добавлено сверх списка

- Главная со списком дел: перезаборы со сроком, неотправленные заказы, ближайший курьер, новые заключения, недооформленный заказ.
- Общий поиск в шапке: номер заказа, фамилия, штрих-код пробирки, код или название теста.
- Автосохранение формы: незаконченный заказ не теряется при звонке или перезагрузке; при старте нового заказа кабинет предлагает сохранить старый в черновики.
- Подстановка пациента из прошлых заказов по фамилии.
- Поля для НИПТ появляются только при выборе НИПТ; правила старого кабинета (срок от 10 недель, многоплодная беременность и т. п.) не блокируют молча, а объясняют причину.
- Пол подставляется по отчеству; проверка пола для тестов вроде AZF и НИПТ.
- Тест 1681 добавляется автоматически к 1724 и виден в заказе как часть комплекта.
- Установление отцовства: второй участник в том же заказе, этикетки на каждого.
- Перезабор в один клик: пациент, исследования и биоматериал подставляются; можно отказаться от перезабора.
- Вызов курьера: выбор заказов, бумажные направления, правило «на сегодня до 13:00, без выходных», подсказка про термоконтейнер, отмена вызова.
- Массовые действия в списке заказов: штрих-коды, вызов курьера, выгрузка.
- Выгрузка заказов и прайса в Excel (CSV).
- Все заключения пациента одним списком.
- Подсказка расхода пробирок за 30 дней при заказе расходников.
- Перенос срока выдачи виден в заказе и в заключениях.
- Мобильная версия: таблицы превращаются в карточки.
- «Аналитика» (по запросу менеджеров партнёров): перезаборы, заключения в срок и доля заказов через кабинет в сравнении с обезличенными средними по всем партнёрам или по региону; заказы по месяцам; «Кто направляет»: заказы, сумма и самое частое исследование по каждому врачу клиники; что заказывают чаще; причины перезаборов; для клиник ЭКО — доля эуплоидных эмбрионов по возрасту пациенток, эмбрионы без результата и мозаичные в сравнении с другими клиниками, кнопка «Запросить подробный отчёт». Выгрузка в Excel.
- «Закрывающие документы» (предложение Полины Близнецовой): документы приходят из ЭДО после закрытия месяца. По каждому месяцу статус подписи в ЭДО и «Пакет PDF»: акт оказанных услуг, счёт и реестр исследований с шапкой Геномед, как в рассылках партнёрам. Реестр также в Excel. «Скачать за период» собирает пакеты за несколько месяцев в один PDF. За текущий месяц доступен только реестр в Excel. Суммы совпадают с «Аналитикой» и «Моими заказами».
- Направивший врач обязателен в заказе: выбор из списка врачей клиники, для нового врача — «Другой врач…». По этому полю строится блок «Кто направляет».
- «Нужны печатные брошюры?» в «Библиотеке»: кнопка «Заказать тираж» открывает «Расходные материалы» с брошюрами уже в заказе.

## Что нужно от лаборатории перед запуском

- Действующие тексты преаналитики (сейчас условные), правила объединения пробирок по отделам.
- Утверждённый текст ИДС Panorama и бланка заказа.
- Реальный прайс, сроки и коды. Коды 1724, 1438, 1681, 0002, 0005, 0006, 0013, 0020, 0023, 0197, 0552, 0554, 0856, 1139 взяты из текущего кабинета, остальные условные. Уточнить, оплачивается ли 1681 отдельно.
- Формат этикеток (в старом кабинете EAN-8 45 мм, здесь Code128).
- API лабораторной системы: заказы, статусы, заключения в PDF, курьеры.
- Для аналитики: какие показатели лаборатория готова считать и показывать, правила обезличивания (минимальное число клиник в сравнении), деление по регионам. Для ПГТ-А: возрастные группы, учитываются ли донорские циклы, какие показатели эмбриологии можно раскрывать.
- Для закрывающих документов: какой комплект выдаётся (акт, УПД, счёт, счёт-фактура), оператор ЭДО, указывается ли НДС, кто в клинике имеет доступ. Сейчас доступ к разделу показан в профиле клиники у роли «Бухгалтер».
- Для врачей: выгрузка формы «Врачи» (ФИО, специальность, привязка к клинике), кто добавляет нового врача по заявке из кабинета.

## Устройство

- `index.html`, `css/app.css` — разметка и стили.
- `js/logic.js` — правила без интерфейса: маска даты, пробирки, права на редактирование, статусы, проверки НИПТ и курьера.
- `js/data.js` — демо-данные и каталог.
- `js/store.js` — состояние и действия.
- `js/pages/*` — разделы кабинета, `js/print.js` — печатные формы.
- `js/vendor/` — Preact + htm (MIT) и JsBarcode (MIT), подключены файлами, без сборки.

Проверка правил: `node tests/logic.test.mjs`.
